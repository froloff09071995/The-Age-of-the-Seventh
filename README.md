# Век Седьмого / The Age of the Seventh

Политико-экономическая историческая сага в вымышленном средневековом мире **без магии**.

Главный герой — седьмой ребёнок короля, младший принц, который не стремится занять престол. Его путь — строительство дорог и институтов, образование, торговля, банковское дело, дипломатия, оборона и передача власти следующему поколению.

## Книги
1. **Земли и люди** — возраст героя приблизительно 16–25 лет.
2. **Союзы и короны** — приблизительно 25–34 года.
3. **Война шести королевств** — приблизительно 34–40 лет.
4. **За пределами знакомого мира** — с приблизительно 40 лет; текущая книга.
